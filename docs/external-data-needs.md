# 투자설명서 밖에서 받아야 할 데이터 (메모)

투자설명서 OCR만으로는 채울 수 없어서, 크롤링 담당자에게 따로 요청할 항목이다. 2026-11-10 정리.

| 데이터 | 쓰일 축 | 비고 |
|---|---|---|
| 일별 순자산(AUM), 시가총액 | 규모 | 투자설명서에는 연말 기준 3년치만 있음 |
| 거래대금, 거래량, 호가 스프레드 | 안정 (유동성 실측) | |
| 구성종목, 섹터 비중 (PDF 구성내역) | 유형 분류 | 같은 업종 비교군을 묶는 데 필요 |
| 업종·테마 분류 체계 | 유형 분류 | 비교군 기준. 투자설명서에는 "국내주식형" 같은 넓은 유형만 있음 |
| 외부 평가 등급 | 정성 | 선택 사항 |

## 검토 후 제외한 것
- 실제 분배금 지급 이력과 분배율: 투자설명서에 없어서 지금은 뺀다. 인컴 축을 다시 살릴 때 필요하다.
- 일별 괴리율, 실측 추적오차: 뺀다.
- 최신 수익률·변동성: 최근 공시 투자설명서 값으로 처리하기로 해서 따로 받지 않는다.
